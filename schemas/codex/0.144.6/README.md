# Codex app-server 0.144.6

This directory contains the stable v2 client protocol bundle and the server-request schema generated by Codex CLI 0.144.6 without `--experimental`, plus synthetic, redacted fixtures for the AC-002 protocol probe. The separate server-request schema is required because server-initiated approval requests are not present in the client protocol bundle.

The fixtures preserve protocol structure only. Thread, turn, item and request identifiers, paths, prompts, model output, commands and diffs are placeholders and do not contain captured user data.
