# Yuanshu UI provenance

The component organization and interaction patterns in this private package are adapted from the public [satnaing/shadcn-admin](https://github.com/satnaing/shadcn-admin) template and the shadcn/Radix approach used by that project.

Yuanshu does not ship the upstream application shell, routes, authentication, demo data, or visual assets. Components are rewritten to use Yuanshu semantic CSS tokens and are kept inside the private `@yuanshu/ui` workspace package.

The upstream repository is distributed under the MIT License. Dependency notices and the lockfile remain the source of truth for the installed Radix packages.
